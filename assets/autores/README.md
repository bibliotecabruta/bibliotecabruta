# Fotos de autores

As fotos de autores usadas no site devem ser armazenadas neste diretório e servidas pelo próprio repositório/GitHub Pages.

## Regra

- Não usar hotlink externo como URL definitiva no banco.
- A fonte externa serve apenas para localizar e validar a imagem.
- Depois de validada, a imagem deve ser baixada, salva em `assets/autores/` e o campo `authors.photo_url` deve apontar para o arquivo local.
- Manter `authors.photo_credit` com o crédito/fonte original da fotografia.
- Preferir arquivos estáveis e de boa resolução; não salvar miniaturas, placeholders ou imagens quebradas.

As capas de edições continuam em `assets/capas-edicoes/`.
